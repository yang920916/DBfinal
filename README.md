# DBfinal｜資料庫管理課程專題：選課系統

## 專案簡介

本專案為逢甲大學資訊工程學系「資料庫管理」課程期末專題，主題以「選課系統」為代表，模擬學生在校園選課時會遇到的課程查詢、選課紀錄、學分限制、衝堂檢查與資料驗證等流程。

本專案主要透過 C / C++ 實作選課系統中的資料處理與邏輯判斷，並將資料庫課程中學習到的資料表設計、資料關聯、查詢邏輯與資料驗證概念應用於實際系統情境中。

---

## 專案目標

本專案希望透過選課系統，實作一套具備基本資料管理與選課邏輯的系統，主要目標包含：

* 建立課程資料的讀取與管理流程
* 模擬學生選課情境
* 檢查重複選課問題
* 檢查課程時間是否衝堂
* 計算學生已選學分數
* 判斷選課是否符合學分限制
* 將資料庫概念轉換為實際程式邏輯

---

## 系統功能

### 1. 課程資料管理

* 讀取課程資料
* 顯示課程資訊
* 查詢課程資料
* 建立課程資料索引或查詢結構

### 2. 學生選課功能

* 學生可選擇欲修習課程
* 系統記錄已選課程
* 顯示目前選課清單
* 計算目前已選學分數

### 3. 選課條件檢查

系統會根據選課規則進行判斷：

* 檢查是否重複選擇相同課程
* 檢查課程時間是否衝堂
* 檢查是否超過學分限制
* 檢查輸入課程是否存在
* 檢查資料格式是否正確

## 資料設計概念

本專案以選課系統為主題，主要可拆分為以下資料實體：

| 資料實體       | 說明                            |
| ---------- | ----------------------------- |
| Student    | 學生資料，例如學號、姓名、系級               |
| Course     | 課程資料，例如課程代碼、課程名稱、學分、授課教師、上課時間 |
| Teacher    | 教師資料，例如教師編號、教師姓名              |
| Enrollment | 選課紀錄，記錄學生與課程之間的選課關係           |
| TimeSlot   | 上課時間，用於判斷課程是否衝堂               |

若以關聯式資料庫設計，可將學生、課程與選課紀錄拆分為不同資料表，並透過主鍵與外鍵建立關聯。

## 主要邏輯設計

### 1. 重複選課檢查

當學生選擇課程時，系統會檢查該課程是否已存在於學生的選課清單中。若已存在，則不允許再次加入。

```text
if selected_course already exists in student_schedule:
    reject course
else:
    add course
```

---

### 2. 衝堂檢查

系統會比較新選課程與已選課程的上課時間。若兩門課的時間重疊，則判定為衝堂。

```text
for course in student_schedule:
    if new_course.time overlaps with course.time:
        reject course
```

---

### 3. 學分限制檢查

系統會統計學生目前已選學分，並判斷是否超過學分限制。

```text
total_credit = sum(selected_courses.credit)

if total_credit > max_credit:
    reject course
else:
    add course
```
